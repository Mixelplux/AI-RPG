discoverable by this exact completed arrival; it does not claim arbitrary
pre-existing roadside evidence was caused by player movement. Existing World
State evidence and discovery structures persist the result; save version
remains 1.

new actors or dialogue, route generalization, generic dispatch, predicates,
priorities, pathfinding, schedules, new persistence, or save migration is
permitted. Any failure before final publication leaves live World State and
Scene Snapshot unchanged.
