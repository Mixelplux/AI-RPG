## Integrated behavior and interfaces

`GameEngine.process_command` first offers input to the bounded interpreter,
then retains the accepted legacy route for unrelated/exact commands. One immutable
`ActionFrame` carries operation, objective, selected target, method, restrictions,
recipient and stopping boundary. A structured frame can use the same validation
through `process_contextual_investigation(frame=...)`. Interpretation has no world
authority and does not assemble legacy command strings.

`WestRoadInvestigation` derives candidate access from current location, exact
trace identity, Mara's current presence and the initial investigating phase.
Sanctioned coarse cues are separate from complete clue prose. A local signs scan
can omit the driver; survey stops at leads without discovery/history/time effects.
Accessible marks can be examined directly without a preliminary survey.

`get_investigation_context()` returns copied internal candidates, acquired findings
and unsaved focus. It is not a provider packet. Player perception receives safe
opportunities; the ordinary CLI displays the deterministic qualified operation
result and uses the existing scene refresh. Ordinary discovery/share history IDs
never enter the West-Road resolved-outcome narration interface.

`investigate(*, discovery_id=None)` preserves the legacy no-argument shortcut.
Named examination checks policy access and
`find_selected_investigation_discovery`, then reuses the existing copied candidate,
acquisition history, validation and scene build before publication. Selection is
independent of declaration order; replay of an acquired selected target returns
its known result without acquiring the next declaration.

Supported questioning checks current Mara presence before the existing attributed
account transaction. Reporting resolves one acquired finding and one present
supported recipient before `present_clue`; existing recipient receipts and history
remain authoritative. Tracks and Mara's account are separate acquisitions and
separate disclosures. Mentioning a lead never earns a receipt.

Ordinary scanning/inspection is implied only within the validated local method.
Unsupported methods, mixed operations, conflicting restrictions, ambiguous subjects
or new consequential commitments stop before effects. No following, travel,
conversation, broadcast or patrol choice is inferred from a broad objective.
This is bounded compositional interpretation, not universal language understanding.

Simulation retains traces, discoveries, history, actor knowledge, phase and cost.
Survey/examine/question/report retain zero elapsed-hour cost. Existing travel and
explicit decisions keep their established costs; Elin still requires both actual
receipts before the original decision becomes eligible.

One focus contains a frame, scope location, at most four subject references and
four accepted event references. Travel suspends it. Resumption and fresh input
revalidate stable identities; return and bare confirmation execute nothing.
Cancellation/conclusion retire only focus. Saving keeps it in the running session;
successful load/reset and exit retire it with a visible notice; failed load/reset
preserve it. No lead ledger, saved focus or new World State/save field exists.
Save version remains 1. Runtime rollback covers failed acquisition/report
preparation, validation and scene construction. Adapter failure cannot repeat an
accepted action and uses the existing qualified fallback.
