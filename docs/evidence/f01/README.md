`engine/narrative_realization.py` at repository root. Fixtures remain in
`test_fixtures/f01_*.json`. Historical reports' `.artifacts` and tool paths are
original execution locations; this directory supplies portable published evidence.
Temporary historical evaluation entrypoints remain preserved locally under
`.artifacts/f01-publication-v1/excluded`, outside the feature worktree. Execution
bridges, credentials, raw provider responses and owner saves are not publication
artifacts. Future live reproduction requires separate authorization and suitable
provider access; frozen requests do not guarantee identical stochastic output.
