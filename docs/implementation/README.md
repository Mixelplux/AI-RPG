# Implementation

Implementation builds approved designs and verifies actual software behavior.
Production behavior is evidence of what works, not authority to redefine intended
gameplay. Significant design conflicts return to Design for owner consideration
under the existing workflow. These entry points add no procedures or approval gates.

Existing sources remain at their original paths:

- [Project](../../PROJECT.md) and [agent contract](../../AGENTS.md) — purpose, ownership and execution boundaries.
- [Workflow](../../WORKFLOW.md) and [engineering posture](../engineering_posture.md) — authorized work and proportionate verification.
- [Runtime architecture](../architecture.md) — implemented structure and boundaries.
- [Current capability package](../current_capability_package.md) — current scope or completed disposition.
- [Lifecycle JSON](../current_sprint.json) — sole machine-enforced lifecycle authority; [current sprint](../current_sprint.md) is its explanatory record.
